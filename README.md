# Портфолио Михаила Погодаева

Сайт-портфолио продуктового дизайнера Михаила Погодаева в строгой минималистичной эстетике.

## 🚀 Стек технологий

- **Разметка и логика:** Семантический HTML5, чистый JavaScript (ES Modules)
- **Стилизация:** Vanilla CSS с CSS-переменными (Design Tokens) для светлой и тёмной темы
- **Сборщик:** [Vite](https://vite.dev/) с мультистраничной конфигурацией (Rollup Multi-Page)
- **Типографика:** Шрифт Inter

---

## 💎 Особенности проекта

### 1. Архитектура и клиентский роутинг
- Быстрый клиентский роутер на History API без перезагрузок страницы.
- Полноценная поддержка прямых переходов и перезагрузки на любых маршрутах:
  - `/` — главная страница («привет» и недавние проекты)
  - `/cases` — галерея всех кейсов с баннерами
  - `/cases/uiren-go` — кейс Uiren Go
  - `/cases/spichka` — кейс Спичка
  - `/cases/leadership-academy` — кейс Академия Лидерства
  - `/cases/good-restaurants` — кейс Good Restaurants
  - `/contact` — контакты

### 2. Страница кейсов с интерактивными баннерами
- Полноформатные интерактивные баннеры проектов с эффектом плавного масштабирования при наведении.
- Чёткая структура информации: название, сабтайтл продукта и роль.

### 3. Детальные страницы кейсов (в стиле Артёма Костина)
- Презентация каждого проекта в формате структурированного кейса:
  - Ключевые факты: **Аудитория**, **Задача**, **Роль** (список обязанностей)
  - Сторителлинг: **Контекст и старт**, **Концепция и дизайн**, **Результат**
  - Крупные адаптивные мокапы интерфейсов и айдентики
  - Циклическая сквозная навигация между кейсами внизу страницы

### 4. DecryptedText Cipher (эффект расшифровки)
- Текстовый скремблер заголовков секций и названий кейсов (`cipher-title`), запускающийся при входе на страницу и повторно при наведении курсора (`mouseenter`).

### 5. Тёмная и светлая темы
- Минималистичный текстовый переключатель (`тёмная / светлая`).
- Автоматическое сохранение выбранной темы в `localStorage` и синхронизация цвета мета-тега `theme-color`.

## 🛠️ Запуск и разработка

### Установка зависимостей:
```bash
npm install
```

### Запуск локального dev-сервера:
```bash
npm run dev
```
Сайт будет доступен по адресу `http://localhost:5173/`.

### Сборка для продакшна:
```bash
npm run build
```
Оптимизированные статические файлы генерируются в директории `dist/`.

### Предпросмотр продакшн-сборки:
```bash
npm run preview
```
