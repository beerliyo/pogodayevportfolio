# Портфолио Михаила Погодаева

Сайт-портфолио продуктового дизайнера в минималистичной эстетике.

## Особенности реализации
- **Точная эстетика stevenpu.com**: фиксированный правый сайдбар на десктопе, минималистичный мобильный навбар, чистая типографика на шрифте **Jost**, поддержка темной (`#0a0a0a`) и светлой (`#ffffff`) тем с автоопределением и ручным переключателем.
- **Интерактивное меню кейсов**:
  - Пункты меню: **Опыт**, **Кейсы**, **Контакты**.
  - Подпункты раздела «Кейсы» раскрываются как по ховеру, так и по клику на «Кейсы»:
    - `- Uiren Go`
    - `- Spichka`
    - `- Академия Лидерства`
    - `- Good Restaurants`
  - **ScrollSpy**: активный пункт и подпункт автоматически подсвечиваются при скролле страницы.
- **Эффект DecryptedText (Cipher)**: динамическая анимация расшифровки заголовков («привет», «RECENTLY», «contact») при попадании в область видимости и при наведении курсора.
- **Карточки проектов**:
  - Uiren Go (Middle Product Designer / Brand Designer)
  - Spichka (Junior Product Designer)
  - Академия Лидерства (UX/UI Design, фриланс)
  - Good Restaurants (UX/UI Design, фриланс)
  - Раскрывающиеся блоки «Подробнее о кейсе» с задачами, решениями и артефактами.
- **Контакты**: быстрые ссылки на Telegram, LinkedIn, копирование Email в буфер обмена в один клик.

## Запуск проекта

### Локальная разработка:
```bash
npm install
npm run dev
```
Сайт будет доступен по адресу `http://localhost:5173/`.

### Сборка для продакшна:
```bash
npm run build
```
Готовая оптимизированная сборка создается в папке `dist/`.
